# Hamass Nagieb — GitHub Pages Portfolio

A responsive portfolio website inspired by the supplied visual reference:
warm cream + dusty rose palette, editorial serif typography, handwritten accents,
curved photo composition, orbit labels, and clean AI-engineer positioning.

## Files

- `index.html` — all portfolio sections
- `style.css` — responsive visual design
- `script.js` — mobile navigation + reveal animations
- `assets/hero-photo.png` — hero workspace image
- `README.md` — deployment/editing instructions

## Before publishing

Open `index.html` and replace:

- `YOUR_USERNAME` with your GitHub username
- `YOUR_EMAIL@example.com` with your email
- Project titles/descriptions/links with your real projects
- LinkedIn URL with your real profile
- The "Download Resume" button can later be connected to your PDF

## Free GitHub Pages deployment

1. Create/sign in to GitHub.
2. Create a **public** repository named exactly:
   `YOUR_USERNAME.github.io`
3. Upload all files from this folder, keeping the `assets` folder.
4. Open the repository → **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. Your site will be available at:
   `https://YOUR_USERNAME.github.io`

It can take a few minutes for the first deployment to appear.

## Optional custom domain

You can later connect a domain you own through GitHub Pages settings.

## Important

This is a static site, so it works perfectly with GitHub Pages.
No backend, server, database, or paid hosting is required.
